Activer OpenRouter

  1. Créer une clé API OpenRouter.
  2. Dans les variables Render, ajoute et colle la clé comme valeur. Choisis Save and deploy.
  3. Ajoute la clé dans dans le fichier .env, puis relance le service avec docker compose up -d.
  4. Une fois le déploiement terminé, reviens ici, actualise et clique sur Tester le modèle.

Aucun achat de crédits ni abonnement n’est nécessaire pour utiliser le routeur gratuit.
