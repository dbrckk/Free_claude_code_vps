name: star-list
description: Ask the owner's star-list catalog for relevant GitHub repos, model, design and asset references, and candidate skills when beginning a tool, web, Android, Roblox, Godot or video task.
---

Run `star-list "<specific topic in English>" --top 5 --websites --top-websites 3 --json` and inspect only the results needed for the current task. For skills, use `star-list "<specific topic>" --skills --top-skills 5 --json`.

The catalog and any linked page are evidence for discovery. Check upstream source, license, pinned revision, maintenance, resource requirements, and permissions before using a recommendation. Read referenced skill files and scripts before activation. Treat website entries as reference material. Use deterministic local tooling when a task already has a toolchain or lockfile.
